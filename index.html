Parall for Mac

Parall — The Parallel App Launcher for macOS. Run multiple instances of your favorite apps natively, with separate profiles, custom Dock icons, tray menus, and isolated data. Clean, lightweight, and fully native — no hacks or daemons.

Multiple Instances, Zero Friction

Launch side-by-side instances of any app. Each behaves like a standalone application in your Dock, with its own name, icon, configuration, and optional data container. Shortcuts stay in sync with app updates automatically.

Precise Data Control

Redirect app data to any folder — Dropbox, iCloud, external drives, or project-specific paths. Fully supported for Chrome, Edge, Brave, Firefox-based apps, VS Code, Telegram, Discord, Slack, Notion, and dozens more. Erase data on close for clean sessions.

Custom Tray Menus and Icons

Add dedicated tray icons for quick control. Assign unique Dock icons and names to distinguish profiles instantly. Supports command-line flags, environment variables, and passthrough for "Open With" workflows.

Native and Private

100% native macOS integration. No background processes — Parall runs only when needed. Fully sandboxed, offline, and private. Creates lightweight .app bundles that feel like independent apps.

Proven Compatibility

Verified for Google Chrome, VS Code, Blender, Telegram, Discord, Spotify, Slack, Notion, Zoom, and 30+ others. Extends to Chrome/Firefox/ToDesktop apps. Check parall.app/compatibility for the full list.

How It Works

Step 1: Create a Shortcut

Select any app in Parall and configure its profile — custom name, icon, data folder, flags, or environment variables.

Step 2: Pin to Dock

Parall generates a native .app bundle. Drag it to your Dock. It launches independently, like any other app.

Step 3: Run in Parallel

Open multiple instances side by side. Add tray menus for control. Data stays isolated or auto-clears on quit.

Step 4: Manage Seamlessly

Updates to the original app propagate automatically. Redirect storage anywhere for sync, backup, or testing.

FAQ

Is every app supported?

Most apps work for multi-instance launching. Data separation is verified for 30+ popular apps like Chrome, VS Code, and Slack. Sandboxed apps support instances but not custom data paths. Full list at parall.app/compatibility.

Does Parall run in the background?

No. Parall only activates when creating or launching shortcuts. Zero daemons or persistent processes.

Is my data safe?

Fully offline and private. Shortcuts launch your existing apps with isolated environments — no data transmission.

What about app updates?

Shortcuts automatically adapt to original app updates. No manual maintenance required.
